{% elif step == 2 %}

2. Discord-bot-token

  1. Ga naar discord.com/developers/applications en klik op New Application.
  2. Open het tabblad Bot, zet Message Content Intent aan en klik Save Changes.
  3. Klik op Reset Token, kopieer het token en plak het hieronder.
  4. Klik op Test: je krijgt dan ook de link om de bot op je server uit te nodigen.

{% endif %} {% elif step == 3 %}

3. OpenRouter-API-key

  1. Maak een (gratis) account op openrouter.ai.
  2. Ga naar Keys en klik op Create Key. Een limiet van $0 is prima: de bot gebruikt gratis modellen.
  3. Plak de key hieronder en klik op Test.

4. Server, kanalen en jouw ID

Zet in Discord eerst Gebruikersinstellingen → Geavanceerd → Ontwikkelaarsmodus aan. Daarna kun je met rechts klikken op een server, kanaal of jezelf en ID kopiëren kiezen.

Laat je de kanaal-ID's leeg, dan gebruikt de bot de kanalen met de naam #hulp en #geheugen.
